# 📊 Sistema Interactivo de Gestión Académica (C++ & PSeInt)

¡Bienvenida a mi repositorio! Este proyecto presenta una solución integral para la gestión de notas y operaciones matemáticas básicas, implementado tanto en lenguaje de bajo nivel (**C++**) como en lógica formal (**Pseudocódigo en PSeInt**).

## 🚀 Descripción del Proyecto
Este sistema permite automatizar el registro de estudiantes basándose en una lista predefinida, realizar cálculos aritméticos y gestionar un registro de notas con validaciones estrictas (rango 0-10), calculando promedios, notas máximas y mínimas.

### 🛠️ Funcionalidades Clave
*   **Lectura Automática:** Carga de base de datos de estudiantes desde archivos `.txt`.
*   **Validación de Datos:** Control de rangos para calificaciones (0.0 a 10.0).
*   **Persistencia:** Guardado de resultados finales en un archivo de texto externo.
*   **Multilenguaje:** Lógica aplicada en C++ robusto y Pseudocódigo estructurado.

## 📂 Estructura del Repositorio

*   `/src`: Contiene el código fuente en `.cpp`.
*   `/pseudocodigo`: Archivo `.psc` para ejecutar en PSeInt.
*   `estudiantes.txt`: Base de datos de nombres (Acosta, Andrade, Guanotoa, etc.).
*   `resultados.txt`: Log generado con los promedios calculados.
